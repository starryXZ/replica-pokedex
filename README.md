## 🚀 Sobre o Projeto

O **Pokédex Project** é uma aplicação web desenvolvida com **HTML, CSS e JavaScript**, que recria uma Pokédex funcional utilizando dados reais consumidos da **PokeAPI**.

O projeto tem como foco o aprendizado de:

- Consumo de APIs REST
- Manipulação do DOM
- Organização de código JavaScript
- Estilização responsiva
- Boas práticas no front-end

---

## ✨ Funcionalidades

- 🔍 Listagem dinâmica de Pokémon  
- 📄 Exibição de nome, imagem e informações básicas  
- ⚙️ Consumo da PokeAPI via Fetch API  
- 🎨 Interface estilizada e intuitiva  
- 📱 Layout responsivo para diferentes telas  

---

## 📊 Tecnologias e Linguagens

| Tecnologia | Função |
|-------------|--------|
| **JavaScript** | Lógica da aplicação e consumo da API |
| **HTML5** | Estrutura da aplicação |
| **CSS3** | Estilização e responsividade |
| **PokeAPI** | Fonte dos dados dos Pokémon |

📈 **Distribuição das linguagens (GitHub Stats):**
- JavaScript — maior parte da lógica
- CSS — estilização da interface
- HTML — estrutura base

---

## 🧩 Padrões e Boas Práticas Aplicadas

- Separação de responsabilidades (HTML, CSS e JS)
- Código JavaScript organizado e reutilizável
- Uso de funções para renderização dinâmica
- Consumo assíncrono de API com `fetch`
- Estrutura simples e escalável
